📘 คู่มือระบบรับฝากเงิน

1. หน้า Login

ผู้ใช้งานต้องเข้าสู่ระบบก่อนใช้งาน โดยกรอก Username และ Password

  • กรอก Username และ Password
  • สามารถเลือกจดจำข้อมูลได้
  • กดปุ่ม "เข้าสู่ระบบ"

2. หน้ากรอกข้อมูล

เป็นหน้าหลักสำหรับบันทึกรายการฝากเงิน

  • กรอกรหัสสมาชิก (8 หลัก)
  • กรอกข้อมูลผู้ฝาก
  • เลือกธนาคารและบัญชี

3. ดึงข้อมูลอัตโนมัติ

เมื่อกรอกรหัสสมาชิก ระบบจะดึงข้อมูลจากฐานข้อมูลให้อัตโนมัติ

  • แสดงชื่อ-นามสกุล
  • แสดงสังกัด และเบอร์โทร
  • เลือกบัญชีเงินฝาก
  • แนบสลิปได้ (Drag & Drop หรือ Upload)

4. ยืนยันข้อมูล

ก่อนบันทึก ระบบจะให้ตรวจสอบข้อมูลอีกครั้ง

  • แสดงรายละเอียดทั้งหมด
  • ตรวจสอบความถูกต้อง
  • กดยืนยันเพื่อบันทึก

5. ดาวน์โหลด PDF

หลังจากบันทึก ระบบจะสร้างไฟล์ PDF

  • ดาวน์โหลดได้ทันที
  • หรือโหลดภายหลังจากระบบ

1. หน้า Login

เข้าสู่ระบบ Dashboard เพื่อดูรายการ

  • กรอก Username / Password
  • กดเข้าสู่ระบบ

2. รายการของผู้ใช้งาน

แสดงเฉพาะรายการที่ผู้ใช้งานทำไว้

  • แสดงประวัติรายการ
  • ดูสถานะรายการ

3. รายละเอียดรายการ

สามารถดูรายละเอียดธุรกรรมแต่ละรายการ

  • ข้อมูลสมาชิก
  • ข้อมูลธุรกรรม
  • ดูสลิป
  • ดาวน์โหลด PDF

4. รายการทั้งหมด (หัวหน้าฝ่าย)

สามารถดูรายการทั้งหมดในระบบ

  • เรียงจากล่าสุด
  • ตรวจสอบข้อมูลได้ทั้งหมด

5. Filter และ Export

ค้นหาและกรองข้อมูลได้หลายรูปแบบ

  • ค้นหาชื่อ / รหัส / จำนวนเงิน
  • ค้นหาตามช่วงวันที่
  • ค้นหาผู้ทำรายการ
  • Export เป็น PDF / Excel
